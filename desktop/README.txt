Stremio Party for Windows

1. Install Stremio 5 for Windows from https://www.stremio.com/downloads.
2. Extract this whole ZIP. If Stremio is open, exit it from the Windows system tray.
3. Double-click Stremio Party.exe in the extracted folder.
4. To host, open a movie or episode and choose Watch Party > Create party.
5. To join, open Watch Party, enter your friend's code, and choose a stream of the same cut.

The desktop launcher loads the bundled interface from this computer and uses your installed Stremio player. Internet access is required for Firebase room sync and online streams.
